数据安全承诺：所有工具在你的浏览器本地运行，粘贴/上传的数据不会发送到任何服务器。 点击查看详细说明 ▾

🧐 为什么是安全的？

本工具箱是纯静态站点：云端只负责把 HTML/JS 代码发到你的浏览器，之后所有处理都在你的电脑上完成，数据全程不离开本机浏览器。

✅ 你可以这样验证

  • 断网测试：打开工具后关闭 WiFi，工具照常工作 = 证明没往外传
  • Network 面板：F12 → Network → 粘数据点处理 → 没有新请求 = 数据在本地

📌 建议注意事项

  • 共享电脑用完后请刷新页面或关闭 tab
  • 工具默认不使用 localStorage 持久化数据
  • Excel 相关工具会从 jsDelivr CDN 加载解析库（仅加载库文件，不上传你的数据）
